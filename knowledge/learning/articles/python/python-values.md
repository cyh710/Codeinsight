# 变量、值与类型

## 先建立直觉 {#overview}

变量是指向对象的名字，值是实际的数据，类型决定数据支持哪些操作。在 Python 中，a = b 通常让两个名字指向同一对象，不是把一份数据放进另一个盒子。理解名字与对象的关系，可以解释为什么修改列表有时会影响另一个变量。

## 原理与执行过程 {#mechanism}

执行赋值时，右侧表达式先求值，再把结果对象绑定给左侧名字。整数、字符串等对象不能原地修改；列表、字典等对象可以改变内部内容。动态类型表示同一个名字后来可以绑定不同类型，不表示每个操作都能自动转换。作用域决定从哪里找名字，生命周期与引用关系决定对象何时可能被释放。

## 跟着例子理解 {#example}

以下是独立教学示例，不代表被分析项目的实际代码。

```python
items = ["笔记本"]
cart = items
cart.append("钢笔")
copy = items.copy()
copy.append("书包")
print(items)  # ['笔记本', '钢笔']
```

## 一步一步读懂 {#walkthrough}

items 先指向一个列表。cart = items 没有创建新列表，append 通过 cart 修改的仍是同一对象。copy() 创建新的外层列表，因此给 copy 添加书包不会改变 items。可以画两个箭头指向一张列表来理解前两句，再为 copy 画第二张列表。若列表元素本身也是列表，浅复制仍会共享那些内层对象。

## 常见误解 {#pitfalls}

变量声明的类型注解一般不自动检查运行时值。== 比较值是否相等，is 比较是否为同一对象，不能用 is 判断任意字符串相等。可变对象作为默认参数会跨调用保留变化，这不是 Python 随机行为，而是默认值对象在函数定义时已经建立。

## 工程中的取舍 {#tradeoffs}

共享可变对象能减少复制，但增加了隐藏耦合。接口如果只需要读取集合，可以使用只读约定、不可变结构或复制；大对象深复制则可能很贵。读代码时遇到一个意外变化，先追对象是否被多个名字共享，再决定是否加锁或复制，避免用复杂机制修补简单的别名问题。
