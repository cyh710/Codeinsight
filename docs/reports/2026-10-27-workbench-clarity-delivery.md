# 工作台减少辅助标签与说明：交付记录

日期：2026-10-27。基线 af1a7c3，分支 codex/workbench-clarity。
依据用户批准的八项审查建议；请求 0015，ADR 0032。

## 实现

| 审查项 | 调整结果 |
| --- | --- |
| 局部教材解读 | 去掉说明小标题和原问题复述，保留一段项目解读与首个位置；其他位置展开查看，随后直接进入相关章节。 |
| 材料区 | 通用类型标题仅保留辅助技术语义，由页签和正文标题识别材料；新来源提醒在材料可见时只在右栏显示，隐藏时改由顶栏提示。 |
| 回答尾部 | 教材来源、查阅过程、代码事实、推断及核查原文统一置于“来源与核查”；复制为快捷图标，恢复问题进入回答菜单。 |
| 提问关联 | 紧凑条目显示具体位置，完整名称和选区按需展开，固定使用有名称及按压状态的图标；取消后保留主动跟随入口。 |
| 左栏 | 移除“工作区”和常驻路径；项目菜单仍可读完整路径；普通对话单行显示，完整时间在悬停提示中，运行、失败、中断、待核实和未读状态保留。 |
| 项目导览与关系图 | 去掉重复区域标签、模型调用实现说明和常驻操作教程；保留问题入口、列标题、按钮及静态关系的边界提示。 |
| 来源卡 | 位置、片段、概念入口直接可读，检索分数及通道移入“检索详情”；教材继续明确标为教材来源。 |
| 保存状态 | 移除常驻底栏；保存中在顶栏显示带名称的旋转图标，保留固定空间避免保存时导航抖动；保存失败持续显示原因。 |

“阅读全文”保持 15px 字号、至少 40px 高的主按钮。正文和代码字号不缩小。
直接发送的“追问”标识、证据不足、旧版本、关系不确定、任务失败、保存失败及移除确认保留。
核查展开后，事实与推断仍分别展示；不改变回答文本和核查结果。

测试同时发现局部教材页恢复跟随时未重新关联当前章节：补齐对阅读模式的订阅，
不修改存储模型或导航身份。固定、取消、重新跟随，以及切材料后的目标隔离已覆盖。
