# 源码重新定位与文件夹窗口交付

## 已实现

- 失效源码提示显示原路径，并提供“重新定位”入口；索引失败也可重新选择后重试。
- 同一项目 ID 下选择新 Git 根目录并重建索引，保留名称、对话、回合和浏览器工作记录。
- 接受请求前检查 Git HEAD 与正在进行的任务，受理后预留索引记录，避免重复提交。
- 重建索引和切换路径一起提交；写入失败回滚旧索引和路径，重启中断后可再次重试。
- Windows 使用 `IFileOpenDialog(FOS_PICKFOLDERS)`，提供地址栏、搜索和快速访问。
  原有本机访问限制、窗口锁、取消返回 null 和超时规则保留，不上传目录、不增加依赖。
- 使用基础 Python 解释器直接执行标准库 helper，避免 Windows venv 重定向器退出后遗留
  真正的选择框进程。子进程自有隐藏置顶 owner，窗口不会被浏览器挡住。

织忆使用浏览器 `webkitdirectory`，能够打开现代窗口，但不会返回完整本地路径。
因此参考其系统窗口体验，仍由本机后端获得 Git 路径；不采用文件上传替代索引。
