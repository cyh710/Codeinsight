## 交付内容

| 计划项 | 已实现的行为 |
|---|---|
| 灵活布局 | 左右区域开关、拖拽、键盘调宽和复位；对照/专注阅读；窄窗口单区阅读，返回原业务视图 |
| 多材料页签 | 代码、教材、概念和回答来源；同版本复用；不同版本区分；关闭其他、溢出列表、最近 10 个关闭页签恢复；方向键切换 |
| 阅读不被打断 | 默认新来源只提示；固定材料不随新答案切换；隐藏区域不会被自动事件重新打开 |
| 多会话 | 项目内新建、改名、置顶、归档/恢复；按标题和消息内容搜索，可切换全部项目；定位命中消息 |
| 后台生成 | 切换会话或项目继续生成；状态与结果归属原会话；另一标签页读取状态并可停止任务；同会话不启动重复生成 |
| 草稿与恢复 | IndexedDB 按会话保存草稿、页签、阅读/对话位置与来路；布局偏好单独保存；存储失败明确提示 |
| 服务重启恢复 | SQLite 保存完整回合与结构化来源，重启后继续使用有效历史；运行中的半轮标记中断并保留已保存内容 |
| 可靠重试 | 稳定请求 ID；连接确认前失败可恢复草稿，刷新后未改动的重试复用请求 ID；已完成请求重放不再次调用模型 |
| 精确选区 | 教材单次连续跨章节选择、代码行列选择；UTF-16 定位；服务端重读并校验版本、范围与预算；客户端预览不作事实 |
| 统一代码阅读 | 文件与符号共用只读 Monaco；13px 字号、自适应高度；前后 200 行窗口、跳行、总行数和版本提示 |
| 导航与上下文 | 地址记录项目、会话、业务视图和材料；浏览器前后/刷新恢复；明确显示跟随、固定或取消的提问目标 |
| 操作反馈 | 多行输入增长、复制回答、来源查看、恢复问题、可读工具状态、搜索失败重试、源码目录不可用提示 |

保留原浅灰与天蓝主题、教材级长文、局部关系图、高级全图、时间线、知识来源与项目证据分离，以及默认折叠的事实/推断。

会话记录和模型窗口分别管理：历史可分页读取；模型继续使用最近六个有效问答对及现有预算，不把全部历史重新塞入模型。
材料视图固定与提问关联固定是两种独立状态；取消关联不会因滚动教材或切换材料悄悄恢复。

- 不增加第三方依赖；复用已有 Markdown AST、Monaco、SQLite 与浏览器原生存储。
