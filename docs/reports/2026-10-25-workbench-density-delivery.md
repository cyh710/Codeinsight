# 工作台视觉密度与操作修复交付

日期：2026-10-25。分支：`codex/workbench-ux`，起点 `17b56d6`。本地提交，不合主线、不推送。

## 用户要求与实现

沿用浅灰与天蓝主题，处理“字小、块大、分界线多、说明多”，并修复第二轮巡检的问题。

- 正文 15px、代码 14px、常用控件 13px、辅助信息至少 12px；图标管理按钮 32×32px。
- 回答取消大卡片外框，教材去掉重复框线，代码块保留浅底但减少边框；背景与留白承担层级。
- 会话列表显示标题、时间与短预览，“改名／置顶／归档”收进菜单，保留键盘入口。
- 材料栏缩减常驻按钮，阅读锁定与跟随选项收进菜单；完整路径和版本可通过页签提示检查。
- 查找按需展开；搜索标明已加载范围，按匹配消息计数，支持上一条／下一条。
- 精简首页、输入框和导入说明，导入名称／版本选项默认折叠。
- 教材长文完整保留，搜索命中章节可直接跳转；事实和推断继续默认折叠。
- 生成时保留可读工具状态，已完成的查阅过程默认折叠，可展开检查失败项与细节。

## 巡检问题处理

| 项目 | 结果 |
|---|---|
| 恢复问题覆盖草稿 | 有不同的未发送草稿时先确认替换，可取消并保留草稿；不自动发送。 |
| 图中选区提问不回对话 | 教材与代码选区均先切回对话，保留草稿并聚焦输入框。 |
| 菜单被正文覆盖 | 共用 portal 浮层；动作完成、外部点击、Escape 均关闭，支持键盘移动和焦点返回。 |
| 阅读章节名滞后 | 跟随滚动同步更新章节 ID 和标题，固定目标继续保持原内容。 |
| 来源卡片丢行号和版本 | 传递真实命中行及已有来源版本；旧来源无版本时明确说明打开当前索引。 |
| 导入等待整次索引 | 服务器接受任务后结束提交弹窗，后台轮询保留项目归属，不回写后来选择的项目。 |
| 搜索和展示不足 | 已处理加载范围提示、前后定位、字号／热区、会话辨识、材料层级、教材章节直达。 |

阅读滚动由工作区显式保存；关闭材料阅读区的浏览器自动锚定，避免调整宽度时再叠加一次滚动补偿。
完整历史全文搜索接口没有新增；当前会话查找明确基于已加载消息，可继续加载更早记录。
