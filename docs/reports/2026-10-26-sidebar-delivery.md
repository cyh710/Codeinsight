# 左侧项目与对话导航交付记录

日期：2026-10-26。分支：`codex/project-exploration`。请求 0014，ADR 0031。

## 本轮变化

用户将范围更正为左栏。本轮重构项目管理、对话列表及文件入口，保留右侧阅读器。
沿用浅灰、天蓝配色，缩减边框和重复摘要，以项目、操作、时间分组组织导航。

- 顶部项目切换器显示项目名称、截断路径及完整路径提示；项目菜单提供复制路径、重新定位源码、移除项目。
- 对话和文件使用图标导航；新建对话、搜索、筛选入口集中排列。
- 对话按置顶、今天、最近 7 天、更早分组；普通列表显示标题和时间，搜索结果才展示匹配片段。
- 生成中、失败、中断、待核实与未读结果保持可见；改名、置顶、归档、恢复和跨项目搜索保留。
- 文件树继续支持路径和符号搜索；原有草稿、材料、后台回答、拖宽和阅读恢复机制保留。

## 移除项目

入口：项目名旁 `⋯ → 移除项目…`。
确认框说明清理索引、全部对话和阅读记录，勾选确认后才能提交。
磁盘源码与内置教材保留；服务端只通过项目外键级联清理 CodeInsight 数据。

新增 `DELETE /projects/{id}`。事务内检测未结束索引、运行中的会话回合及 Agent 任务；
发现忙碌状态返回 409，提示等待索引和回答结束或先停止回答，不自动取消任务。
请求失败保留当前项目和草稿，可取消或重试。

成功后清理该项目的浏览器草稿、材料和待处理请求缓存，再切换到剩余项目。
移除最后一个项目显示导入入口。其他项目、布局偏好不清理。
本地缓存清理失败单独提示，不伪装成服务端移除失败。

schema 4→5 原地新增项目 ID 高水位表；API 和 CLI 分配统一使用，防止移除后的 ID 复用。
旧链接、其他浏览器中的旧草稿不会因此命中新导入项目。
迁移保留已有项目、索引与历史，不要求重新建立索引。

## 启用方式与提交边界

重启 CodeInsight 启动器，加载新后端 API 并自动执行原地迁移，然后刷新前端。
仅刷新网页不会让旧后端获得移除接口。本轮未强制停止用户服务。
成果形成本地提交，不合并主线，不推送远程。
收尾时检测到另行修改的 `AGENTS.md`，保持原状并排除在本轮提交之外。
