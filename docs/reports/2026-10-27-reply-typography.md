# 回复排版与代码引用链接

日期：2026-10-27；分支 `codex/reply-typography`，基线 `67e712e`。
用户要求参考 Codex 的回复排版，并将代码引用变成右侧阅读入口；请求 0022，ADR 0039。
本轮使用 frontend-design 技能，保持现有中文字体和浅灰、天蓝工作台风格。

## 实现

- 对话正文使用独立排版变体：16px 正文、清楚的标题层级、舒展的段落与列表，
  表格主要保留水平分隔，引用块减少底色。教材原有排版、选区与图文布局保持原样。
- 代码块显示语言并提供复制反馈；代码保持横向滚动，不挤宽页面，不新增编辑或执行功能。
- `[path:line]` 与 `[path:start-end]` 均可识别。已核实引用在正文显示为
  `hybrid.py:19–23` 这样的文件名链接，悬停提供完整路径；不再要求有 exploration 才启用。
- 链接只匹配结构化来源的同路径与起始行，范围定位已核实的起始行，不扩张证据资格。
  普通点击打开右侧代码；地址沿用已有项目、会话、材料与源码版本模型，支持浏览器修饰键
  和新标签页，刷新后仍可定位。代码内容、行内代码和已有链接不自动改写。
- 流式未收尾时不启用引用，未知或无效来源保持文字；原回答 Markdown 与复制全文不改写。
- 不新增依赖，不改 API/SSE/schema，也未改后端生产代码。
