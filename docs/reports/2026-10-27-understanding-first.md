# 理解优先回答改版交付

本轮移除了“无引用就自动算推断、继而整篇降级”的处理链。主正文连贯呈现，关键来源仍可打开；资料缺口在具体段落说明。位置能对应不再被描述为解释已经得到证明。

基线 `4355a3e`，特性分支 `codex/understanding-first`。请求 0023 / ADR 0040 已记录用户授权；本地提交，不合 main、不推送，保留 `.zcode/`。

## 已交付的行为

- 主问答与共享讲解 Prompt 不再要求逐句引用或事实/推断栏目，保留按问题选择具体例子、过程和对比的规则。
- 无引用的解释不自动填入 `inferences`，普通回答不再因缺引用弃答。`facts` 等旧字段保留形状，只用于兼容，不作语义评级。
- 无效引用不成为链接，相关文字保留，问题位置收进详情。代码示例及已有链接不参与正文引用提取；范围检查拒绝超出实际查阅窗口的目标。
- 成功读取的源码片段进入最终材料列表，流式与刷新后的来源一致。右栏分开显示正文引用与本轮查阅；教材资料按需展开，避免把全部检索命中当作结论支持。
- 去掉正文前全篇核查提示、分类色块和置信度百分比；旧对话正文不重写。错误、中断、保存失败与版本问题继续保留操作反馈。
- 概念深层说明使用连贯正文；旧 `inferences` 独有文字作为普通解读保留并去重，项目位置仍可点击。`quick/project` 继续零模型调用。
- 探索脉络与完整历史不再受旧评级门槛限制；只记录已展示内容和来路，不表示用户掌握。最近六对有效历史、上下文预算、版本与会话隔离保持。
- 不根据教材检索结果自动凑满三个后续入口。明确的知识动作可恢复无正文代码引用的解读；普通教材链接保持完整教材阅读路径。
- 无新增依赖、端点或 schema 迁移。原有不限总轮次、SSE 心跳、完整正文和停止能力保持。

## 阅读检查与未达理想之处

以下是实施者对完整样本的阅读检查，不是初学者用户研究，也没有调用评分模型。

- **模块作用**：新版能分别说明检索、证据选择、生成的分工，策略与成绩分开讨论，并指出 `generate.py` 读取失效；首题仍有资料报告式开场，尚未充分从用户直觉切入。
- **跟随过程**：新版取舍回答解释了文档覆盖与每篇块数的关系，也指出 `per_doc=1` 时开关差异很小。续讲用 A/B/C 文档命中表逐步演示，能看出改变的是证据选择而非检索本身；两版修正前文后都能完成这一路径。
- **预测改动**：样本能解释提高每篇块数会挤占固定预算下的文档覆盖。但有“同文档块”被顺口说成“邻居”的表述，需要核对，不能把分组与相邻块扩展当成同一机制。
- **具体缺口**：多数回答能区分注释记录的代理指标和未读取的端到端成绩，没有补造策略排名。但仍存在把检索未命中扩大为“目录/成绩不存在”的措辞，不符合新版要求。
- **默认值语境**：新版查询流程回答仍把函数默认 `doc_grouped` 的描述放进运行流程，容易与配置中的 `doc_diverse` 混淆。位置校验无法解决这个语义问题，未通过后处理隐去它。
- **信息密度**：前三题仍有两三千字和十余个来源，不能宣称已经消除模板化或适合全部初学者。后续若继续优化，应围绕这些具体样本改进例子和实际配置语境，而不是恢复全篇评级或机械截断。

工程行为已验证；真实内容质量仍有上述限制。没有用引用数量、推断条数、点击量或停留时长代替理解效果，也不声称用户已经掌握。
