# 0008. 关系图改为局部阅读，保留高级全图

- 日期：2026-10-25；实施分支：`codex/frontend-refinement`。
- 用户反馈：“关系图不是给人看的”。
- 已确认方向：“局部阅读图为主，保留高级全图”。
- 需求依据：规格 §2.2-6/7、§2.6；前端接手授权见请求 0007。

## 发现与交付

实际预览默认返回 80 节点、66 条关系，45% 缩放使 12px 文字仅约 5.4px。
按连接度排序还会混入测试、脚本和通用辅助函数，无法代表一个业务问题的结构。
因此新增阅读方式，原 ADR 0017 的确定性布局继续用于高级全图。

- 默认先选当前代码、已索引流程入口或搜索函数/类，不自动绘制整张概览图。
- 局部视图按真实调用方向分为“谁调用它 → 当前代码 → 它调用什么”。
- 保留实际字号；左右各先显示 4 项，余项有明确数量并可展开。
- 测试按索引文件角色分组并默认折叠；缺少角色时才使用明确的测试路径约定。
- 同一目标的多处调用合并卡片，调用行号和不确定性保留。
- 查看详情不换中心；“以此为中心”继续探索，支持返回上一个中心。
- 调用位置跳转到调用方的真实文件行，源码和概念入口继续可用。
- 窄中栏纵向排布，当前代码优先显示；不通过缩小字号塞下图。
- 高级全图保留原来的搜索、跳数、关系类型、平移缩放与概念标签。

## 证据与边界

只使用现有 `/graph`、符号、流程和概念接口，不改冻结契约，不改后端，不增加依赖。
局部视图请求一层调用、上限 200 节点；响应截断时明确说明，所有数量只表示当前返回的关系。
调用方向由 `src/dst` 判断，不从跳数猜测；调用图不描述运行时顺序。
未解析的动态调用和仓库外目标不能被本视图补成有位置的项目节点。
递归单独说明，推测关系不升级为确定关系；不生成未经验证的中文功能说明。
无命中、读取失败和缺少中心分别呈现，失败可重试；旧项目请求不能覆盖新目标。
