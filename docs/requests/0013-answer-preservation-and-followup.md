# 0013. 保留回答与续问取证

- 日期：2026-10-26；状态：用户批准实施，承接项目探索分支。
- 范围：统一修改 Agent、会话投影、API、前端与冻结契约，不推送、不合并主线。

## 契约

Answer、非流式及 SSE 最终 answer 增加可选 raw_text、response_kind、evidence_review。
raw_text 保存最终生成原文；text 保存可阅读正文，未核实引用转为不可点击标记。
evidence_review 区分 verified/partial/knowledge/unverified/no_match/unavailable，记录真实检查结果、
未通过引用、索引身份及可选来源回合。abstained 保留兼容含义，但不再控制正文可见性。
新增字段保存在现有 answer_json，不升级 schema，不补造已丢失旧正文。

## 行为

“听不懂/换种说法”等续问从同项目同会话上一轮取上下文；来源仅作查找线索，
同版本代码通过现有只读工具重新读取，教材按版本重读。旧版本不静默换成当前行号。
明确阅读目标优先；内部取证不改用户草稿或关联。没有前文时简短澄清。
证据不足仍展示正文与轻提示；伪造引用不能点击或进入事实；未核实输出不自动成为可信历史或探索要点。

## 验收

无工具、真实无命中、工具失败、部分引用失效、基础知识、续讲、无前文、跨会话、旧版本、
刷新与重启、SSE 最终正文不消失；离线 Provider，真实模型调用 0。
