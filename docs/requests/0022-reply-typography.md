# 0022. 回复排版与代码引用链接

- 日期：2026-10-27；状态：用户要求代码引用点击在右栏展示，正文参考 Codex 回复。
- 分支：`codex/reply-typography`，基于 `67e712e`，保留此前修复。
- 本地提交、不自动合并或推送；保留 `.zcode/plans/`。

正文采用现有浅灰、天蓝风格下的简洁排版：更清楚的字号、行距与标题层级，
列表与表格减少分隔噪音，代码块提供语言提示及复制操作，不加重复说明或装饰卡片。
样式限定在对话回答，不改教材阅读布局、工作台空间或来源折叠规则，不引入依赖。

支持 [path:line] 和 [path:start-end] 两种引用，将已校验来源显示为文件名＋行号链接，
悬停查看完整路径，普通点击在右侧定位，修饰键保留浏览器打开链接的行为。
跳转身份带当前项目、会话和已有源码版本。范围引用定位已校验的起始行，
不把客户端正文中的范围扩大为新的已核实证据。无效引用、代码块、行内代码及既有链接不改写。
不再依赖 exploration 元数据才启用引用；流式未收尾的来源仍不可点击。

沿用 API/SSE/schema，不改冻结契约。覆盖有范围、单行、重复引用、旧回答缺少探索字段、
无效目标、源码版本、键盘与窄窗口；前端 test/lint/build 与浏览器真实阅读路径验收。
