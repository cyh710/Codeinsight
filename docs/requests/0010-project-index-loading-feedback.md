# 0010 · 项目导入与索引加载反馈

- 日期：2026-10-26
- 状态：用户要求补充导入与建立索引的前端加载提示，沿用跨线实现授权。

前端沿用浅灰／天蓝样式与 202 后关闭弹窗的约定，补充常驻状态、等待时间、文件树准备态、
完成计数、失败及状态检查中断的可操作反馈。仅显示现有接口确认的状态，不编造百分比或
扫描／解析阶段。自动检查到上限时允许继续检查，网络失败不误报索引失败，也不自动重发导入。
轮询按项目隔离；刷新或重新选择索引中的项目后恢复检查。

现有重复导入没有预留 index_run，受理后 GET 可能仍返回旧 ready，导致前端提前显示完成。
修正为正常导入也先预留运行记录，复用请求 0009 的原子重建服务完成该记录，不增加重复时间线
记录。保留 Git ref，失败回滚旧索引，重启中断标记为失败。API 形状不变，不增加依赖。
同时修复固定 tag／commit 的 ref 被解析为空、误与当前 HEAD 比较而显示过期的问题。
