# 请求 0007：工作台会话、材料与精确选区契约

- 状态：用户于本会话明确批准完整工作台改版计划；按该授权统一实施 A/B/C 相关目录。
- 不推送远程，实施分支 `codex/workbench-ux`；保留原有未提交调查材料。
- 契约增量：会话列表/创建/详情/更新/回合/取消任务 API；问答 request_id；完整结果落盘；
  reading_context 的版本、UTF-16 原文选区；源码窗口总行数和版本指纹。
- SQLite 原地升级，保留索引与账本；模型最近六轮与展示全历史分开。
- 前端多会话/多页签；IndexedDB 保存每会话工作区，localStorage 保存布局。
- 原 SSE 事件词汇和旧请求继续兼容；教材来源与项目证据继续分开。
- 不增加新依赖。Markdown 原文位置映射复用现有 remark；服务端只读取受维护正文和源码。

具体行为和验收以用户批准的 CodeInsight 工作台改版计划及 ADR 0020 为准。
