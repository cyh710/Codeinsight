# 0014. 左侧项目与对话栏重构

- 日期：2026-10-26；状态：用户明确更正为左栏并授权直接重构，右侧阅读器不在本轮范围。
- 沿用浅灰天蓝风格；参考 Agent 工作台的信息层级，不新增自动开发或编辑功能。

## 范围与契约

紧凑项目头部及管理菜单、清楚的新建/搜索操作、置顶与时间分组的对话、可见的运行/未读状态、
按需筛选、已有文件树；保留会话草稿、后台生成、归档和定位能力。
新增 DELETE /projects/{id}：仅移除 CodeInsight 的项目索引、会话与账本，不删除磁盘源码或教材。
服务端事务内检查索引/问答忙碌状态，忙碌返回 409；前端必须显示影响范围并经明确确认后调用。
移除成功清理该项目浏览器缓存并切换到剩余项目；删除最后项目时显示导入入口。

## 身份与迁移

项目 ID 不能在移除后复用，否则旧 URL、浏览器草稿可能串入新项目。
schema 4→5 原地新增 project_id_counter，高水位分配项目 ID；API 与索引器统一使用，
保留其他项目全部数据，不重建索引。前后端 API 类型同步新增移除响应。
删除功能只在临时夹具验证，不移除用户实际项目。本轮本地提交、不合并、不推送。
