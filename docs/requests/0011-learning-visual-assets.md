# 0011. 教材图文资源、版本与阅读契约

- 提出方：统一实施（知识资产、API、前端）。
- 日期：2026-10-26。
- 状态：用户要求提交当前工作区后按图文教材计划实施；先完成图文闭环与三篇样章，评审后扩充。

## 增量与兼容

- 知识资产新增可选 `assets.json` 及 `assets/`。图片 ID 全局稳定，归属文章及章节，记录作者、许可、来源、尺寸、说明、预期内容哈希。
- `GET /knowledge/topics/{id}` 增加 `assets` 数组，旧客户端可忽略。返回资源 ID、章节、标题、图意、作者、许可、尺寸及带内容哈希的 href，不公开文件系统路径。
- 新增 `GET /knowledge/assets/{asset_id}/{sha256}`，仅返回当前清单中的受维护资源。哈希、归属与实际字节匹配才返回；旧地址、缺失资源、损坏资源返回明确错误。资源失败不阻断教材文字。
- Markdown 用 `![图注](/knowledge/assets/{asset_id})` 引用，前端仅用同一文章返回的已解析资源替换为 `/api` 下的版本化地址。不依赖远程图片或运行时图形库。
- 图片实际字节与元数据参与所属文章版本及教材快照指纹；旧页签沿用版本失效提示，不悄悄混用新旧内容。
- 图注可按原文选择；图中标签不伪装成 Markdown 原文选区。模型读取章节的文字与图意，不读取 SVG 源码或远程图片。
