# ADR 0037：分析总轮次由完成或停止决定

- 日期：2026-10-27；状态：已接受；请求 0020，修订 ADR 0010 的默认模型轮次。

固定 10 次调用会在跨模块研究中耗尽，已读取资料仍无法进入最终汇总，用户得到的是轮次
告警而非答案。提高到另一个固定值仍有相同问题，默认改为 0（不限总轮次）。
正数只保留为调用方主动启用的兼容限额，不作为生产默认。每次模型请求仍按原有预算
选择最近的完整工具交互组；上下文长度与总调用次数是两个不同维度。
不新增另一种固定总时长、自动重发或不透明的死循环判定来替代轮次中断。

等待模型时每 15 秒发 SSE 注释心跳；它只证明后端连接仍在，不表示检索取得进展。
客户端收到实际流字节就更新连接活动时间，注释不生成消息、查阅步骤或持久化事件。
模型服务自己的网络超时仍产生真实错误；主动停止、浏览器断线及服务重启按既有机制中断。
没有网络活动时原有 watchdog 仍负责结束失联连接。

默认不限制总轮次意味着长问题可能产生更多模型调用，不能把它描述成质量或结果保证。
若出现反复检索，应以可观察的实际样本改进检索与任务规划；不悄悄恢复全局硬上限。
