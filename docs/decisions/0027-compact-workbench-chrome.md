# ADR 0027：收细分隔线与压缩顶部工具区

- 日期：2026-10-26
- 状态：用户要求分隔线更细、顶部占用更少。

分隔线从占位 6px 改为 1px，通过透明伪元素向两侧各扩 4px 保留拖动命中范围。
关闭侧栏时只保留 1px 边缘提示，不显示整条灰色拖动带。材料区取消重复的左边框。
布局预算与遮罩边界共用分隔线宽度，避免视觉尺寸变更后再次出现遮罩挡住拖动条。

顶栏从 54px 收到 42px；材料工具栏压到 36px、页签按钮收至 26px；
对话工具栏压到 36px。正文与教材字号不变，常用按钮保持至少 28–30px 高。
索引状态在宽窗口并排显示标题与说明，窄窗口仍允许换行，不截断错误和操作入口。

使用真实浏览器验证线宽、透明命中区、拖动／开关、键盘调整、遮罩与窄窗口排版。
不改默认面板宽度、阅读内容或状态恢复规则。

## 验证

Vitest 123 项、Playwright／Edge 38 项通过，ESLint 与构建通过。
浏览器在 900、1024、1100、1280、1440px 实测顶栏 42px、分隔线 1px；
拖动开关、调宽、键盘调整、面板隔离、阅读位置和草稿恢复回归通过。
