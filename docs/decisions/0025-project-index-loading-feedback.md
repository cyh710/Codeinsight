# ADR 0025：项目导入与索引加载反馈

- 日期：2026-10-26
- 状态：用户要求补充前端加载提示；请求 0010。

202 后关闭导入弹窗，工作台顶端以紧凑状态条继续呈现，侧栏隐藏或切换视图后仍可看见。
状态按项目记录，完成不会切走当前阅读。仅展示接口确认的状态，不显示百分比或伪造的
扫描、解析进度。等待时间从本页观察到任务时开始，不宣称为服务端总耗时。

区分建立索引、同步界面、完成、索引失败、状态暂不可读与检查暂停。网络故障和五分钟
检查上限仅提供恢复检查，不自动重发导入；重试索引须用户点击，使用本次记录的原请求。
服务端恢复的失败项目没有原请求时，可重新选择目录。完成后显示实际文件／符号数量，
可查看文件或关闭提示。刷新或选择运行中的项目恢复检查；首次文件树展示准备占位。

正常导入先预留 index_run，避免旧 ready 被误当作新任务完成。预留记录由原子索引服务
收尾，保持一项操作一条记录；失败保留旧索引，后端重启后可明确重试。
对于明确指定的 tag／commit，保留原 ref，而非使用可能为空的 `--abbrev-ref` 结果，
避免把正确建立的固定版本索引误报为过期。

每个受观察项目至多一个轮询，沿用两秒间隔，单轮最多五分钟。提示不做独立永久存储，
刷新后通过项目详情恢复当前项目的运行或失败状态。本轮不扩展全项目后台任务中心。
