# ADR 0039：正文排版与代码链接跟随回答

- 日期：2026-10-27；状态：已接受；请求 0022。

用户希望更接近 Codex 的回复阅读体验，并明确要求文件引用点击打开右侧代码。
已有编号引用只匹配单行且依赖 exploration，导致范围引用及部分旧回答无法点击。

对话回答使用独立的排版变体，保留现有中文字体与天蓝强调；正文优先，避免重复标签。
正文引用显示文件名和行号，完整路径放悬停提示。教材的既有排版与默认编号模式保留。
代码块提供语言与复制，表格以水平分隔为主，不增加编辑、执行或语法高亮依赖。

引用只匹配结构化 citations 中的同路径和起始行，范围不扩张证据资格；点击定位起始行。
普通点击拦截并打开右栏，链接地址沿用工作区 URL 模型，带项目、会话与已有版本。
流式来源未核对前保持文字，代码内容与已有链接不自动改写。来源身份不能由显示名称推导。
