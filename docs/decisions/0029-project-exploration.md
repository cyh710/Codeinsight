# ADR 0029：以当前问题组织项目探索

- 日期：2026-10-26；状态：用户批准实施；请求 0012。

## 决策

项目导览只读当前索引，展示有依据的问题入口，不自动调用模型。缺少简介就说明缺少，不用统计数字伪装项目职责。
回答随问题组织，不规定 400 字或通用教材段落。来源保持原始可验证位置，前端只把已解析引用变成短编号。
内部 propose_exploration 工具提交结构化建议；只有经服务端验证的附加信息进入最终答案。静态边不是运行轨迹，设计意图和反事实不能被合法行号自动证明。
明确点击追问即发送，原草稿及其关联目标不受影响。动作携带来源标识，服务器重读其问题与材料，不执行客户端提供的任意命令。
局部解读源自同一已保存回答；教材本身保持独立维护、完整可读，不额外生成或写回正文。
探索脉络只记录本会话已展示内容，绑定索引版本；索引变化时标旧并重新取证。最多十二条，模型占用不超过 4KB，仍计入原上下文预算。

## 取舍

结构和位置校验不能证明解释语义正确，真实模型质量及初学者理解单独验收。概念 quick/project 仍不调用模型，新的项目讲解由明确追问发起。模型工具结果允许没有流程或推荐，不为了视觉完整性补造对象。
会话新增列采用 schema 4 原地迁移；不删除索引，不清理历史。首版不增加实时工作区索引、运行追踪或用户能力画像。
