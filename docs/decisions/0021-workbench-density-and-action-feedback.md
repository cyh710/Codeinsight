# ADR 0021：工作台视觉密度与操作收尾

- 状态：已采纳。用户于 2026-10-25 明确要求修复第二轮巡检问题，并调整“字小、块大、分界线多、说明多”的展示。
- 范围：沿用浅灰与天蓝主题、原三栏和全部阅读功能；不修改教材正文，不增加依赖或冻结接口。

## 决策

正文 15px、Monaco 14px、常用控件 13px、辅助信息至少 12px。
用背景、字号与适量留白区分层次，移除回答外框、反复出现的管理链接和非必要分隔线。
会话管理收进可键盘访问的菜单，列表展示更新时间和简短预览；查找按需打开。
教材保留完整正文，目录、版本选项和来源继续按需展开。选区操作仍然可发现。

菜单经 portal 放入文档顶层，避免阅读区 sticky 工具条拦截鼠标。
支持动作后关闭、点击外部关闭、Escape 及焦点返回；对话管理和材料控制使用同一组件。
阅读内容锁定与提问目标固定继续独立，文案明确控制对象。

恢复旧问题遇到已有草稿时先确认替换；选区提问先回到对话再聚焦，不发送问题。
跟随阅读时章节 ID 与标题一起更新；来源卡片传递命中行号与已记录版本，旧来源缺版本明确提示。
导入 POST 返回 202 后结束提交弹窗，轮询继续归属原项目；后到结果不回写新项目。

教材搜索继续按文章合并，同时保留可以点击的章节命中。当前对话查找显示匹配消息数量，
支持前后定位；有未加载历史时明确范围并提供加载入口，不把局部查找宣称为完整历史全文搜索。

## 代价与重评

更多菜单比常驻链接多一步，但减少了小点击目标与重复文字；重要发送、选区提问和返回入口仍常驻。
本轮不引入完整会话搜索接口、全文加载或新的索引任务取消接口。
文件夹选择依赖运行服务加载请求 0008 路由；此前重启被自动审批拒绝，本轮不绕过该限制。

用实际页面及离线浏览器测试验证草稿保护、菜单层级、选区回到对话、来源位置、异步索引和窄窗口。
真实模型效果与人工观感评审单独记录，不由自动化测试代替。
