# ADR 0022：工作台动效的边界与状态规则

- 状态：已采纳，用户明确要求改善僵硬的前端交互。
- 沿用现有字体、浅灰／天蓝视觉、布局与功能，不增加依赖。

## 决策

复用已有 motion/easing 令牌：按压 80ms，菜单与内容切换 150ms，侧栏和导航选中态 220ms。
侧栏开关平滑让出空间，左右内容带小幅方向感；专注阅读与返回用轻微淡入提示模式变化。
拖拽时取消缓动并结束未完成的开关过渡，尺寸直接跟手，结束／取消／丢失捕获均清除拖拽状态。

侧栏使用现有 Presence 机制，在退出结束后才隐藏空间，子树始终保留。
关闭当下设置 inert 和 aria-hidden，退出期间不能再次操作内部控件；快速重开取消旧退出。
材料、业务视图按导航身份入场，不把轮询、草稿更新和流式字符更新当作新入场。
主导航选中背景滑动；常用按钮有悬停与按压反馈。

菜单有进出动画，关闭当下释放焦点及键盘监听，退出期仍保留最后位置，不能点击穿透回旧操作。
原有弹窗的遮罩、进入与退出动画继续复用。
支持的浏览器中 details 平滑展开高度；其他浏览器保持原生开关和淡入，不影响阅读。

运行时订阅 prefers-reduced-motion；开启后直接隐藏退出内容，不等待动画兜底计时器。
所有新增动画和导航伪元素过渡一并降级。
对话与材料滚动均由工作区维护，禁用浏览器自动锚定，避免侧栏动画重排后重复补偿滚动位置。

## 代价与重评

侧栏宽度过渡会触发短时间文本重排，但仅用于离散开关，持续 220ms；拖拽完全禁用过渡。
若超长会话导致布局卡顿，应使用性能实测决定是否改用更复杂的画面快照过渡，本轮不引入该机制。
固定宽度的侧栏内容层保留阅读位置及组件状态；窄窗口关闭材料时以绝对定位完成淡出，避免挤压主视图。

离线浏览器验收覆盖中间过渡帧、退出禁用、快速反向操作、拖拽跟手、阅读位置恢复、
动态切换系统偏好及既有完整探索路径。真实模型调用为零，观感由实际页面和录屏辅助评审。
