# ADR 0038：探索附加工具不能隐式撤回正文

- 日期：2026-10-27；状态：已接受；请求 0021。

propose_exploration 只整理已核对的后续入口，不读取新的项目事实。模型可能先写完整答案，
再在同轮调用它；之后输出的只是补充，不能据“最后一轮”就推断前文应丢弃。

运行时显式保留只伴随探索附加工具的文本，正常结束后与最终文本合并；包含关系与完全
重复按原文去重，不按长度、标题或模型猜测选择答案。其余检索过程叙述仍不直接成为正文。
保留的正文与补充一起接受既有事实/引用校验，raw_text 保存对应原始文本，
前端继续以服务端最终投影为准，避免客户端拼回未经核查的草稿。
核查过程中单独的换行分隔不作为空主张清除，保持表格行和正文换行，避免恢复后的
多行 Markdown 又在事实拆分时挤成一行。

旧回合恢复复用同一合并规则，从不可变任务事件还原公开正文与取证；引用只依据该回合
记录，当前索引版本必须匹配。先备份、再比较原值更新回合，新增审计事件，不改原始事件。
不自动扫描或改写其他历史，不重放模型，不把恢复理解为模型陈述已通过语义评审。

如果以后新增读取或修改项目的工具，默认仍属于过程工具，不能因名称类似探索而保留其
草稿。若需要用户明确替换已发正文，应另行定义替换语义，不能靠最后一轮隐式覆盖。
