# 0040 · 理解优先，来源提供定位而非整篇评级

- 状态：已接受，用户批准计划（2026-10-27）
- 替代：ADR 0007 的强制分栏、无引用即推断及无引用即弃答；ADR 0030 中与这些规则相关的全篇提示与历史限制。

## 决策

完整自然语言正文是主要解释。少量关键位置链接帮助进入实现，来源详情保存正文引用和本轮查阅。位置核对只证明目标可定位，不能证明句子语义正确。通用原理、类比和因果串联没有引用也不自动成为推断。

保留旧接口形状：`facts` 为对应有效位置的原文片段，`inferences` 不再自动填充，普通新答案的 `abstained` 默认 false；失败与未完成由现有错误和任务状态表达。`evidence_review` 的旧状态只兼容读取，不能决定整篇展示、历史或探索脉络。无效位置从正文引用中移除但不删除解释，保存在详情；代码示例不作为引用处理。

历史只作对话来路，脉络只表示讨论过的内容。最近六个完整问答对继续受既有上下文预算约束，旧版本需重新查阅。旧正文不批量重写；旧概念中仅存于推断字段的独有文本作为普通解读保留。

不根据检索命中自动补足知识推荐；后续动作由当前问题的实际理解收益决定，最多三个。`quick/project` 不调用模型，深层讲解使用连贯正文；不增加语义分类或审稿调用。

## 边界与代价

仍要求不能编造代码、位置或成绩；缺口就在相关段落说明。静态不确定调用保留具体说明。来源失效、工具失败、保存失败与模型中断仍需可操作反馈。

旧 `verified/partial/abstained` 与新版行为不可直接比较。引用覆盖率不作为理解质量代理，使用固定案例检查模块作用、过程、取舍和改动影响。真实十条回答只是小样本，不证明统计优势或用户掌握。

## 重评条件

当实际阅读显示特定项目判断仍容易被误解时，改进该处的表达和来源入口，不恢复对所有无引用句子的全篇评级。若完整来源带来噪声，优先改善折叠与去重，不隐藏解释。
