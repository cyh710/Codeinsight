# ADR 0043 · 正文、来源与学习使用一致规则

状态：接受；请求0026，用户批准完整计划。

## 决策与理由

1. 公开文字已交给用户便不能按后续工具名称撤回。逐模型回合保留原文与段落边界，只去重完全相同的完整片段；来源解析不删除解释。中断和失败保留已持久化文字，不成为完整历史问答。
2. 来源身份由服务端掌握。引用、概念、图、符号和变更位置使用统一target。旧记录缺少版本时只提供明确的当前文件入口，从首行开始；不把旧行号套到新代码。
3. HTTP同回合同文件固定首次版本；MCP每个默认调用独立读取当前文件，显式hash保留历史。每个调用的状态独立，不依赖长期工具容器或互相清理共享缓存。
4. 本轮来源表为模型提供短编号，只在当前请求可用；工作区路径可从本轮已取得材料补全版本，多版本须明确编号。外部MCP跨调用使用完整来源元数据。
5. 动作检查实际依赖：稳定工作区字节和知识版本不依赖索引epoch；关系/图及索引动作保留索引检查。
6. 静态流程只能沿真实call边，低置信边明确标记，副作用是启发式候选；模块包含函数不能冒充调用。旧候选在读取时核对，历史正文不改写。
7. 用户选择轻量自动教材：明确术语唯一匹配时最多一节；无关普通项目问题不预加载。显式知识工具仍可查更多，阅读选区不受一节限制。不新增分类模型。
8. 关联阅读显示已有知识链接所在完整Markdown块，可展开来源全文，不用一条takeaway代替已有解释。没有匹配块不强凑关联。

## 实现约定

- 请求读取状态使用ContextVar隔离；MCP默认调用另开SQLite连接与读取事务，检索器同步绑定该连接，结束时关闭，不提交其他调用的事务。
- 变更位置在既有JSON中保存对应来源target，不新增列或迁移。旧变更只在真实历史快照可恢复时补出身份。
- 已观察到同路径多个来源身份时，模型须用本请求返回的source_ref或完整版本选择；最终答案只保存完整身份，不保存临时编号。
- 教材推荐仅来自本轮实际读取目标，不按前置/相关主题自动凑足三个。章内目录及正文相关链接保持可浏览。

## 验证边界

不新增schema或自动重索引；缺失的历史字节不能复原。当前文件按钮不做跨版本行号推断。旧调用流程过滤后数量可能减少，不能为了数量补回假边。真实讲解效果和初学者用户研究另行验收，本轮仅离线工程与页面验证。
