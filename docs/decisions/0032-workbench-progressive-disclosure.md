# ADR 0032：工作台按操作需要展开辅助信息

- 日期：2026-10-27；状态：用户批准审查建议，请求 0015。

重复标签与常驻说明挤占代码、回答和教材空间。材料身份交给页签，操作交给按钮，
元信息按需展开；正常会话使用单行标题，异常和运行状态仍显式呈现。

回答的教材来源、工具过程、代码事实、推断和核查原文统一收进“来源与核查”。
内部事实与推断分开，不赋予待核实文字事实资格。生成中的工具状态继续直接显示。
回答复制和核查保持快捷入口；问题恢复进入菜单，保留草稿替换确认。

局部教材解读保留标题、必要项目解读与可打开的位置，正文之前不重复问题和说明标题。
阅读全文保留主按钮。输入关联显示具体位置、可访问的固定图标及按需选区预览；
取消后保留主动重新跟随入口，不改变阅读状态语义。

新来源仅在可见材料区提示，材料隐藏时由顶栏提示。
保存中使用顶栏状态，错误保留持续提示，不为正常保存单设全局底栏。
检索通道与分数移入技术详情，版本缺失、不确定关系、证据不足和数据删除范围仍显式说明。

若用户无法发现核查或恢复问题，重评入口名称及位置；保持键盘、触屏和辅助技术均可访问，
不依赖鼠标悬停才提供核心操作。
