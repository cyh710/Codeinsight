# ADR 0031：左栏统一项目管理与对话导航

- 日期：2026-10-26；状态：用户批准重构左栏；请求 0014。

项目管理集中在顶部的项目菜单，对话按置顶和时间组织，搜索筛选按需显示。
保留当前项目下“对话/文件”的入口与已有阅读恢复，避免把源码浏览、项目移除和关闭材料混同。
沿用原有浅灰天蓝配色，以文字层级和留白代替密集边框、重复说明和大块按钮。

移除项目清理 CodeInsight 数据，不触碰源码目录；确认框明确索引和所有对话将被清除。
有索引或回答运行时拒绝移除，避免取消任务和删除数据产生竞态。
API 与 CLI 使用持久化高水位 ID，防止 SQLite 复用已删除 ID 造成旧浏览器材料串台。
浏览器清理限定该项目的键，其他项目、草稿和布局偏好保留。

若项目很多、当前项目切换成本显著增加，重新评估项目搜索与跨项目树；本轮不改变会话归属。
