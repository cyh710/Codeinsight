# ADR 0023：Windows 本地双击启动器

- 状态：已采纳；用户要求编写启动器。
- 日期：2026-10-26
- 范围：根目录 BAT、`scripts/launch.py`、启动说明；不修改 API、配置契约或前端。

## 决策与理由

沿用工作台既有的本地双进程运行方式。BAT 固定到自身所在目录，缺少 Python 虚拟环境时
使用 `uv sync --locked --extra dev` 准备环境；Python 启动器复用标准库，缺少前端依赖时执行
`npm ci`。不增加打包框架、Windows 服务、桌面应用或系统全局配置。

后端默认从 `127.0.0.1:8020` 起选择可用端口，前端监听 `127.0.0.1:5173`。
用户实际运行时，8020 被酷狗音乐占用，因此默认后端端口作为优先值而非强制值；
最多检查连续 40 个端口，选择后通过已有 `CI_API_TARGET` 同步前端代理。
显式指定 `--backend-port` 时保持严格，冲突会报错。Vite 严格绑定端口，真实后端就绪后
再打开浏览器。日志写入已忽略的 `.ci/launcher/`，密钥只通过继承环境和原有 `.env` 读取。
使用原有幂等迁移建立／升级数据库，不触发索引、模型或 Embedding 请求。

复用后端必须校验产品名、健康状态与真实数据目录；复用前端还需校验工作台页面和代理。
其他服务不被结束或接管；前端端口冲突时说明原因。操作系统文件锁防止重复双击竞争。
退出或启动失败时只清理本次创建的子进程；已有服务不受管理，也不自动升级或重启。

## 代价与重评

这是源码运行启动器，需要 Python 3.13+、uv、Node.js，首次安装依赖需要网络。
当前采用已存在的 Vite 开发服务器，因此运行期间要保留启动窗口；Ctrl+C 会停止本次启动的
服务，进行中的回答遵循现有中断恢复规则。进程退出后保留日志，不自动清理历史。
如果交付对象需要脱离开发环境安装，再评估静态前端托管或桌面打包。
