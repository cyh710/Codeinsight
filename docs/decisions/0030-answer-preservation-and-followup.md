# ADR 0030：证据校验与正文展示分开

- 日期：2026-10-26；状态：用户批准；请求 0013。细化 ADR 0007 的弃答含义。

没有本轮证据只能说明尚未核实，不能据此声称完整检索无命中，更不能删除整段解释。
保留生成原文与校验后正文；无效引用显示为未核实文字，不授予位置跳转和事实资格。
前端统一展示正常正文，证据状态用轻提示表达；旧弃答记录仍可读，不伪造旧原文。

重述请求以原问题和上轮回答为来路，而非独立检索短语。上轮来源不直接继承为 grounding，
同版本最多重读两处代码，受原上下文预算约束；教材仍按原版本服务读取。
索引更新时要求重新定位，不能用旧行号冒充新实现。明确阅读目标优先，不改客户端关联。

未核实回答可保留在对话历史，但注入模型时明确标记为未核实；不写入可靠探索要点。
来源和引用校验仍不证明讲解的语义正确性，真实模型与人类理解效果另外验收。
若出现续问识别过宽、核查开销过大或提示不能被用户理解，重新评估识别范围和展示密度。
