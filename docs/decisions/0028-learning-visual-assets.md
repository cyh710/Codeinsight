# ADR 0028：图示随教材版本管理，正文与项目证据分开

- 日期：2026-10-26。
- 状态：按用户确认的图文教材计划实施；请求 0011。

## 原因

图片放在前端 public 会与教材安装及内容版本脱节；只在 Markdown 中添加外链也无法保证离线阅读与图意检索。图片加载还可能改变滚动高度，破坏已有阅读恢复。

## 决策

- 原创图示使用可维护的 SVG 与生成脚本，资源随知识包分发，服务端按清单 ID 与内容哈希读取。不新增运行时图形库。
- 清单结构严格校验，缺失/哈希不符的资源在读取端降级，教材正文仍可读取。校验工具在交付时阻止坏资源发布。
- 每篇版本包含其图片元数据和实际内容指纹。未引用图的文章保持原有版本算法，避免全库无谓过期。
- 图注来自 Markdown 原文，可作精确选区；图片本身不产生虚假的文本偏移。复杂图的关键含义另有正文/图意，供文字检索与模型读取。
- 预留图片宽高；放大使用原生 dialog，关闭返回原焦点，不改变当前探索目标。图示入口只在教材中按已解析资源启用。
- 对未变化的 Markdown 内容复用渲染结果。工作台保存滚动位置会更新父组件，不能让这个更新重建自定义 Markdown 组件并丢失图片失败/放大状态。
- 教学图和项目实例区分；事故教材依据固定提交的诊断说明，不把未索引代码编成项目位置。

## 代价与重评

带哈希的旧图 URL 不保留历史图片仓库；旧页签须打开当前教材版本。资源清单修改需与图文一同维护。暂不支持图片内节点选区、多模态 Provider 或在线绘图编辑器；有明确需求时再评估。

三篇样章完成后进入实际阅读评审，再扩充候选主题，避免批量模板化。用户本轮“按计划执行”确认了此阶段安排，不需要再为常规实现重复请求许可。
